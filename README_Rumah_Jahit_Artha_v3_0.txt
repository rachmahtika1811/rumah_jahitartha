RUMAH JAHIT ARTHA v3.0

Upgrade dari v2.0 dengan modul tambahan:
1. Login pengguna + role.
   Default: owner / artha123 (segera ganti password).
2. Manajemen stok bahan.
3. Mutasi stok masuk/keluar.
4. Alert stok minimum.
5. Pengeluaran usaha.
6. Dashboard laba kotor.
7. Manajemen karyawan.
8. Invoice HTML yang dapat disimpan/print ke PDF dari browser.
9. Nomor invoice otomatis AR-TAHUN-NOMOR.
10. Tetap membawa fitur v2.0: pelanggan, ukuran, pesanan,
    produksi, pembayaran, galeri, laporan, WhatsApp, backup.

Menjalankan:
    streamlit run Rumah_Jahit_Artha_v3_0.py

Dependensi:
    pip install streamlit pandas pillow
